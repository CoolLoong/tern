# Security

Tern is a development preview. Fixes are made on the current development branch;
older snapshots do not have separate security maintenance branches.

For a vulnerability involving data loss, malicious filenames, desktop protocol
boundaries or access to private files, use GitHub's **Security → Report a
vulnerability** on `CoolLoong/tern` if private vulnerability reporting is enabled.
If that control is unavailable, ask the maintainer for a private contact channel
without posting exploit details, personal paths, credentials or affected files.

Include the affected commit, operating system, a minimal reproduction using
synthetic data, and the expected versus observed behavior. Do not upload your
workspace state, Recent database or full environment as a reproduction.

See [privacy and local data](docs/privacy.md) for the information Tern stores.
