## Requirements Covered

- R1: 空白左键拖动显示拉框矩形，实时更新
- R2: 按下时无修饰清空选择、有 Ctrl/Shift 保留为基准

## Detailed Implementation Design

### marquee.rs

```rust
#[derive(Clone, Debug)]
pub(crate) struct Marquee {
    pub anchor: gpui_kit::Point<Pixels>,
    pub current: gpui_kit::Point<Pixels>,
    pub was_selected: HashSet<String>,
}

pub(crate) fn marquee_apply(
    table: &Entity<TableState<BrowserDelegate>>,
    bounds: Bounds<Pixels>,
    marquee: &Marquee,
    cx: &mut App,
)
```

`marquee_apply`：矩形 = anchor/current 构成的 Bounds；遍历 `row_bounds` 相交行；`ids = marquee.was_selected.clone()`，对每个相交行 `remove` 失败则 `insert`（XOR）；调用 `delegate.set_marquee_selection(ids)`。

### browser.rs

```rust
pub fn set_marquee_selection(&mut self, ids: HashSet<String>) {
    self.interaction.context_target = ContextTarget::None;
    self.interaction.selected_ids = ids;
    self.interaction.selection_mode = SelectionMode::Marquee;
}

pub fn begin_marquee(&mut self) -> HashSet<String> {
    self.clear_context_menu_target();
    self.interaction.selection_anchor_id = None;
    self.interaction.selection_mode = SelectionMode::Marquee;
    self.interaction.selected_ids.clone()
}

pub fn end_marquee(&mut self) {
    if self.interaction.selection_mode == SelectionMode::Marquee {
        self.interaction.selection_mode = SelectionMode::Idle;
    }
}
```

`SelectionMode` 加 `Marquee` 变体；`drag_select_row` 已有 `dragging || != DragSelect` 守卫，marquee 模式天然不串。

### browser_view.rs render_table_panel

- `let marquee = self.marquee.clone();` → `marquee_rect`/`marquee_layer`（absolute、accent 0.15 填充、accent 边框，id "browser-marquee"）
- `on_mouse_down(Left)`：`marquee_hit_row` 为 None（空白）时：
  - `was_selected = table.update(begin_marquee + state.clear_selection + 无修饰时 delegate.clear_selection)`
  - `view.marquee = Some(Marquee{anchor: pos, current: pos, was_selected})`
  - 行上按下：`view.marquee = None`（行元素自身 row_press 已处理选择）
- `on_mouse_move`：`pressed_button == Left` 且 marquee 存在 → 更新 current + `marquee_apply` + notify
- `on_mouse_up(Left)`：marquee 存在则置 None + `end_marquee` + notify
- `.when_some(marquee_layer, ...)` 插在 canvas 后、DataTable 前

事件顺序注意：左键 mouse_down 用 `on_mouse_down`（非 capture），行元素的事件先于面板（子先父后冒泡），行上按下已被行处理但事件继续冒泡到面板——面板判定 `marquee_hit_row` 命中行时置 `view.marquee = None` 即可，不干扰行选择。
